An alien tourist's one-line review of Earth, in at most 200 characters — judged head-to-head on alien voice, humour and tightness. The program writes exactly one line to `/output/entry.txt`:

> Two days on Earth: the locals worship glowing rectangles, queue for bitter bean water, and call it 'living the dream.' Three stars — the sunsets are lovely, the queues are not.

The line is 176 characters, a single line with no trailing newline. `main.ts` enforces the gate itself (1–200 characters, one line, non-blank, no leading/trailing whitespace, no control characters) before writing.

## Run it

```sh
node main.ts
```
